# 锁定 PX4 版本基线与检索清单

## 目标

把为 PIX 2.4.8 克隆板选定的 PX4 版本基线（v1.13.x）正式写进 project spec，并产出一份本轮组会检索的"目标词 + 产出约定"清单，作为后续检索 issue 的统一依据。

## 范围

- 包含：版本基线决策回写 spec「关键考量」；检索清单成文（各检索面查什么、产出到哪、版本怎么标）。
- 不包含：实际检索执行（属 issue 003–005）；PPT 成稿（属 issue 006）。

## 归属

- 隶属 epic：`.cs/epics/001-x-组会PPT与PX4资料搜集/spec.md`
- 相关 spec：`.cs/spec/index.md`（版本基线回写到这里）

## 背景与证据

- 飞控已购定为 **PIX 2.4.8 克隆板（FMUv2 / STM32F4）**，不换板。
- 核查证据：fmu-v2 target 仍在 `references/PX4-Autopilot/boards/px4/fmu-v2/`（可编译），官方 2026-03 commit `#26928` 仍为其裁剪 EKF2 省 flash（`CONFIG_BOARD_CONSTRAINED_FLASH=y`）；但 3DR Pixhawk 1（FMUv2）已列入 `docs/en/flight_controller/autopilot_discontinued.md`，文档停在 v1.15，`pixhawk.md` redirect 到 discontinued。即"能编但不受官方测试/维护的极限板"。
- 最新 stable 已到 v1.17，HEAD 向 v1.18。用户拍板选 **v1.13.x**（教程匹配 + 已知能跑的最稳基线）。

## 操作方案

- 在 `.cs/spec/index.md`「关键考量」追加一条：**版本基线**——2.4.8 克隆板 → PX4 v1.13.x；说明 discontinued/flash 受限背景与"将来换受支持板再追新"的退路。
- 在 epic「当前推进」勾掉本 issue 并核对检索清单是否仍准确。
- 检索清单要点（供 003–005 使用）：
  - a 单机调试链路：2.4.8/F450 刷机→传感器校准→遥控器→调参→首飞；落点官方 `config/` `assembly/` `flying/` 章节 + notes/001 的 B 站教程。
  - b 仿真：SITL + Gazebo/jMAVSim；落点官方 `dev_setup/` `simulation/` 相关章节 + 本机实测。
  - c 多机协同：MAVLink 拓扑、QGC 多机支持、ROS2/swarm 依赖；落点官方 `advanced_features/` `companion_computer/`。
  - d 学术/应用综述：PX4 在教学/科研/集群的用法，喂 PPT 相关工作页。
- 每条结论标版本与出处；版本号/参数名/板型映射以官方英文文档与源码为准（notes/002 原则）。
