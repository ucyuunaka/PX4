# 演示 A：单机起降一键脚本（含 demos/ 骨架）

## 目标

用户双击 `demos/A-单机起降.bat`：出现 Gazebo 仿真窗口，四旋翼自动起飞 → 悬停约 10 秒 → 降落 → 上锁；窗口保留，按回车后清理干净。双击 `demos/停止全部.bat` 可随时清理并重来。

## 范围

- 包含：`demos/` 目录骨架、共用库 `demos/lib/`、停止脚本、A 演示、`demos/README.md`（白话使用说明）、`demos/A-单机起降/说明.md`（白话讲稿）、`demos/.gitignore`（忽略 `logs/`）。
- 不包含：QGC（B）、多机（C）、录屏文件本身（做完后与用户确认录制方式）。

## 归属

- 隶属 epic：`.cs/epics/002-o-仿真演示与一键脚本/spec.md`（目录约定、调用链、质量约束以 epic 为准）

## 背景与证据

- NAT 下 headless 起降闭环已通过（ff 009，日志 `/root/px4-build/sitl_verify_nat*.log`）；带 GUI 在 NAT 下未复验。
- 启动方式、置参与坑位：`.cs/notes/004-PX4仿真SITL路径.md`；启动器参考 `.cs/env/run_gazebo.sh`。

## 实现设计

### 这次要怎么做

- `demos/lib/common.sh`：环境（干净 PATH、`DISPLAY=:0`、`WAYLAND_DISPLAY=wayland-0`、`GIT_SUBMODULES_ARE_EVIL=1`、`GAZEBO_IP`/`PX4_SIM_HOST_ADDR`=eth0 IP）、中文日志函数、`demo_cleanup`、`sitl_start`（FIFO + `setsid make px4_sitl gazebo`，日志到 `demos/logs/`）、`wait_for <正则> <超时>`（盯日志）、`pxh <命令>`（字面写 FIFO）、`set_failsafe_params`。
- `demos/A-单机起降/run.sh`：清理 → 启动 → 等 `home set` 并稳定几秒 → 置参 → takeoff → 等 `Takeoff detected` → 悬停 10 s → land → 等 `Disarmed` → 提示"按回车结束" → 清理。镜头跟随飞机为可选加分（失败不致命）。
- `demos/stop.sh` + `停止全部.bat`。

### 哪些边界不碰

- 不 `wsl --shutdown` / `--terminate`；不改 `/root/px4-sitl-src` 源码；不改 Windows 防火墙/代理。

### 怎么确认做对

- 带 GUI 连续跑两次都成功（中间只用停止脚本）；有 Gazebo 窗口截图为证；日志有 Takeoff/Landing/Disarmed。

## 验证

2026-10-09 本机实测：

- **`.bat` 链路**：`cmd /c` 直接执行 `demos\A-单机起降.bat` 与 `停止全部.bat`（stdin 接 /dev/null 让 `read`/`pause` 自动过）。中文输出正常（bat 为 UTF-8 无 BOM + `chcp 65001`，中文路径 `A-单机起降` 在 cmd 下解析正确，未用回退方案）。
- **演示 A 连续两次带 GUI 跑通**（中间未手动清理，靠脚本自带 cleanup）：
  - run1 `demos/logs/A-单机起降-20261009-200932.log`：`PX4 SIM HOST: 172.29.171.4` → `Simulator connected on TCP port 4560` → `home set` → `Armed by internal command` → `Takeoff detected` → `Landing detected` → `Disarmed by landing`。起跑到清理完约 39 s。
  - run2 `demos/logs/A-单机起降-20261009-201100.log`：同序列全绿。gzclient 日志行（`Connected to gazebo master`、`GuiIface`）证明 GUI 窗口确实起了。悬停中截图 `demos/logs/A-hover.png`（全屏截图，含 Gazebo 窗口）。
  - 启动到 `Takeoff detected` 约 25–30 s（make 增量检查 + gzserver + px4 init）。
- **`stop.sh` 空跑**：无演示运行时执行，输出"已清理"，exit 0，不误报。
- **镜头跟随**：`gz camera -l` 列出 `gzclient_camera`；`gz camera -c gzclient_camera -f iris` 实测 exit 0（请求已发，但该命令要 ~11 s 才返回，已在 run.sh 加 `timeout 15` 兜底，避免残留进程）。
