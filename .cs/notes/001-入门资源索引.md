# 入门资源索引

## 结论

本项目入门所需的装机、调参、QGC 教程链接集中在这里；软件和固件一律走官方渠道，不依赖网盘镜像。

## 触发场景

装机、刷固件、调参、地面站配置，或向他人介绍入门路径时查这里。

## 证据和细节

### 官方资源（首选）

- PX4 官方文档·基本概念：https://docs.px4.io/main/en/getting_started/px4_basic_concepts
- QGC 官网：https://qgroundcontrol.com/ （含 GitHub releases）
- QGC 下载安装页（各平台直链）：`references/qgroundcontrol/docs/{en,zh}/qgc-user-guide/getting_started/download_and_install.md`（本地源码，官网同款）
- PX4 固件由 QGC 在线刷写，无需单独下载固件文件；QGC 会按飞控板型自动选固件（PIX 2.4.8 克隆板 → `px4_fmu-v2_default`）

### F450 装机

- 装机教程（按飞控类型选合集）：https://www.bilibili.com/video/BV1YRs6eREuq

### F450 操作 / 遥控器

- 操作教程（按遥控器类型选合集）：https://www.bilibili.com/video/BV1WtxgeREGy

### PIX 飞控调参

- PIX 飞控基础调试教程：https://www.bilibili.com/video/BV1MhUKYoEnD
- PIX 2.4.8 固件刷写教程：https://www.bilibili.com/video/BV1cQSNY7EHa
- 调参工具即 QGC 本身：官方调参文档见 `references/qgroundcontrol/docs/{en,zh}/qgc-user-guide/setup_view/tuning_px4.md`（autotune + 手动调参）；PX4 侧调参文档见 `references/PX4-Autopilot/docs/en/config/`

### QGC

- QGC 安装 + PX4 固件刷写教程：https://www.bilibili.com/video/BV1wYzhYFEFz
- QGC 用户指南（含固件刷写、参数、调参全部章节）：`references/qgroundcontrol/docs/{en,zh}/qgc-user-guide/`（本地源码，官网同款）
