# PX4 本地文档查阅

## 结论

PX4-Autopilot 仓库内置完整的官方文档源码（Markdown 格式），内容与官网 https://docs.px4.io 完全一致——官网就是这套源码渲染的。本地查阅具备三个优点：**离线可读**、**可全文搜索**、**可用目录索引定位**。有更新时 `git pull` 同步。

## 触发场景

- 查 PX4 概念、参数、配置方法、API、机架接线等任何文档内容
- 需要确认某个说法在官方文档中的原文
- 向他人解释概念时需要引用官方术语

## 证据和细节

### 文档位置

```
references/PX4-Autopilot/docs/
├── en/          # 英文原版（权威，11MB）
├── zh/          # 中文翻译（Crowdin 同步，11MB）
├── ko/ uk/      # 其他语言
├── assets/      # 图片资源
└── _sidebar.md  # 各语言目录下均有，官方生成的完整目录索引
```

### 使用方式

**人工查阅**：打开 `docs/zh/` 对应章节，或先查 `docs/zh/_sidebar.md` 目录索引定位。中文版与英文版结构一致。

**AI 查阅**：优先用英文版（原版可信度最高，避免翻译滞后或偏差）；同时对照中文版同路径文件，便于用官方术语转述、也方便用户理解。两边有出入时以英文版为准。

### 目录索引

每个语言根目录下的 `_sidebar.md` 是官方自动生成的目录树，与网页版侧边栏一一对应。例如 `docs/en/_sidebar.md` 第一条即 `getting_started/px4_basic_concepts.md`（Basic Concepts）。

### 验证方法

已验证：官网 "Basic Concepts" 页文字与 `docs/en/getting_started/px4_basic_concepts.md` 逐字一致。

### 更新

```bash
cd references/PX4-Autopilot && git pull
```

官网更新后对应提交会进入 main 分支；拉取即同步。文档更新频率低，偶尔同步即可。
