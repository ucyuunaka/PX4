# PX4 / QGC 本地文档查阅

## 结论

本工作区两个官方仓库都内置完整文档源码（Markdown）：

- `references/PX4-Autopilot/docs/` — PX4 官方文档，即 https://docs.px4.io 渲染源
- `references/qgroundcontrol/docs/` — QGC 用户指南 + 开发者指南，即 https://docs.qgroundcontrol.com 渲染源

两者都有中英双语（`en/` 原版权威，`zh/` 为 Crowdin 同步翻译）。本地查阅具备三个优点：**离线可读**、**可全文搜索**、**可用目录索引定位**。有更新时 `git pull` 同步。

## 触发场景

- 查 PX4 概念、参数、配置方法、API、机架接线等任何文档内容
- 查 QGC 安装、固件刷写、调参、界面说明等地面站操作
- 需要确认某个说法在官方文档中的原文
- 向他人解释概念时需要引用官方术语

## 证据和细节

### 文档位置

```
references/PX4-Autopilot/docs/
├── en/          # 英文原版（权威，11MB）
├── zh/          # 中文翻译（Crowdin 同步，11MB）
├── ko/ uk/      # 其他语言
├── assets/      # 图片资源
└── _sidebar.md  # 各语言目录下均有，官方生成的完整目录索引

references/qgroundcontrol/docs/
├── en/qgc-user-guide/     # QGC 用户指南：getting_started / setup_view / fly_view / plan_view / analyze_view / settings_view / releases / troubleshooting
├── en/qgc-dev-guide/      # QGC 开发者指南（自定义构建、插件等）
├── zh/qgc-user-guide/     # 用户指南中文翻译
└── ko/ tr/                # 其他语言
```

### 使用方式

**人工查阅**：打开 `docs/zh/`（或 `docs/en/`）对应章节。QGC 用户指南入口 `docs/{en,zh}/qgc-user-guide/index.md`；PX4 可先查 `docs/{en,zh}/_sidebar.md` 目录索引定位。

**AI 查阅**：优先用英文版（原版可信度最高，避免翻译滞后或偏差）；同时对照中文版同路径文件，便于用官方术语转述、也方便用户理解。两边有出入时以英文版为准。

### 常用落点（QGC 用户指南）

- 下载安装：`getting_started/download_and_install.md`（含各平台直链）
- 固件刷写：`setup_view/firmware.md`
- PX4 调参：`setup_view/tuning_px4.md`（autotune + 手动调参）
- 传感器/遥控器/机架设置：`setup_view/` 下其余文件

### 更新

```bash
cd references/PX4-Autopilot && git pull
cd references/qgroundcontrol && git pull
```

官网更新后对应提交会进入各自 main 分支；拉取即同步。文档更新频率低，偶尔同步即可。
