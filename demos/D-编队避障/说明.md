# 演示 D：编队避障 —— 白话讲稿

## 演示前准备（彩排要点）

- 先双击 `D-编队避障.bat` 跑一遍全程：rviz 窗口出来后，左边一个红色六边形是编队起点队形（黑点是飞机），中间散布灰色块/柱子是树林障碍，7 条彩色线（黄/紫/橙/蓝/绿/粉/青）是各架飞机规划出来的轨迹，整体从左往右飞。
- **断网再试一次**：这套仿真完全本机运行（ROS1 + 简化仿真器，不连 PX4 不连 QGC），理论上断网无碍，但按规矩彩排时断网实测一遍。
- 灰色障碍只会在飞机附近显出来（探测距离有限），不是一开始就铺满全图。
- 这个演示和 PX4 无关：7 架"飞机"是简化数学模型，重点看**规划算法**怎么让队形绕开障碍。

## 组会上可以怎么讲（3–5 句）

- "这个是多机编队规划算法的仿真——用的是浙大 FAST 实验室的开源项目 **Swarm-Formation**，对应论文《Distributed Swarm Trajectory Optimization for Formation Flight in Dense Environments》（ICRA 2022）。"
- "7 架无人机保持六边形队形，自动穿过一片随机生成的树林到对面目标点；中间它们互相同步位置、协同调整轨迹，既保持队形又绕开障碍。"
- "和上一个演示（C）的区别：C 是 3 个真飞控各听指令各飞各的，互相不知道对方；这里是**规划算法**——机器之间协同，队形和避障是算出来的。"
- "这里的'飞机'是简化的数学模型，不是完整飞控仿真——所以它展示的是算法效果，不是飞行手感。我们以后要把这类规划接到真机/真飞控上，那是下一步的事。"

**标注口径**：算法演示仿真，非实机、非完整飞控。

## 可能被问到的问题和答法

- **"这是谁做的算法？"**
  浙江大学 FAST 实验室（高飞老师团队，论文作者 Lun Quan、Longji Yin、Chao Xu、Fei Gao 等）。开源项目叫 Swarm-Formation，论文发表在 ICRA 2022（另有一篇 IEEE T-RO 版本）。这是我本科课程作业用过的开源模板，原样保留作参考，没改算法本身（只把目标点设成自动）。
- **"它们怎么保持队形的？"**
  每架都跑同一个轨迹优化器：既要求"队形相似度"（graph-based cost），又要求避障、动力学可行，三者一起优化；机器之间通过通信（这里是本机模拟的广播）交换位置和计划。
- **"和演示 C 有什么区别？"**
  C 是 3 个 PX4 飞控实例各自独立、由脚本统一发指令，飞机间不协同；D 是规划算法驱动的编队——飞机间共享信息、协同保持队形和避障。两者互补：D 展示"算法长什么样"，C 展示"真飞控多机跑起来什么样"。
- **"障碍是事先知道的吗？"**
  规划器拿不到全局地图。每架飞机带一个**模拟深度相机**（探测距离 5 米），边飞边探测前方障碍、建自己的局部地图、实时重规划——所以画面上障碍只在飞机附近出现。树林本身是随机生成的（这里固定了随机种子，每次长得一样）。
- **"为什么不是真飞机/飞控？"**
  这个仿真专门验证**规划**环节：飞机被简化成数学模型，不用跑飞控，算得快、方便看算法效果。完整飞控（PX4）的仿真在 A–C 演示里展示。
