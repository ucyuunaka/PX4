# 演示脚本使用说明（白话版）

这个文件夹里是组会现场要用的仿真演示。**不用懂命令行，双击就能跑。**

## 现在有哪些演示

| 文件 | 演示内容 | 状态 |
|---|---|---|
| `A-单机起降.bat` | 四旋翼在仿真世界里自动起飞、悬停 10 秒、降落、上锁 | 可用 |
| `B-地面站联动.bat` | QGC 地面站连上仿真飞机，在地面站里点起飞/降落 | 可用 |
| `C-多机同飞.bat` | 3 架仿真四旋翼一起起飞、排队平移、一起降落；QGC 可切换看 3 架 | 可用 |
| `D-编队避障.bat` | 7 架无人机保持六边形队形穿越随机树林避障（Swarm-Formation 规划算法，rviz 画面） | 可用 |
| `停止全部.bat` | 一键清理所有演示进程 | 可用 |

## 怎么用

1. **双击** `A-单机起降.bat`。
2. 出现一个黑色窗口，里面全是中文提示，照着看就行。
3. 稍等片刻（**第一次启动会慢一点**，仿真在加载模型，正常现象），会弹出 Gazebo 仿真窗口。
4. 飞机会自动完成"起飞 → 悬停 → 降落 → 上锁"，全程不用动手。
5. 飞完后 Gazebo 窗口**不会关**，可以指着画面继续讲。
6. 讲完了回到黑色窗口，**按一下回车**，就会自动清理结束。

## B 怎么用（地面站联动）

1. **双击** `B-地面站联动.bat`。QGroundControl 没开的话脚本会先帮你打开（已经开着就不重复开）。
2. 等仿真窗口出来、黑窗口提示"正在给地面站加一条连接"，再看 QGC 左上角是否显示已连接（Ready To Fly / 准备起飞）。
3. 在 QGC 左侧工具条点 **起飞(Takeoff)** 并按提示滑动确认；飞起来后点 **降落(Land)**。也可以在 Plan 页画航线任务上传执行。
4. 演示结束回黑窗口**按回车**，仿真自动清理；QGC 窗口自己手动关掉。

## C 怎么用（三机同飞）

1. **双击** `C-多机同飞.bat`。QGC 没开会自动开。
2. 等仿真窗口出现 **3 架**飞机（3 个飞控同时加载，比 A/B 慢）、黑窗口提示"3 架飞机都已就位"。
3. 之后自动进行：一起起飞 → 整列向东平移 15 米 → 悬停 5 秒 → 一起降落。全程不用动手，QGC 顶部工具栏可以切换看单架飞机。
4. 结束回黑窗口**按回车**清理；QGC 自己手动关。
5. 电脑风扇会明显转起来（3 个飞控同时跑），正常。

## D 怎么用（编队避障）

1. **双击** `D-编队避障.bat`（不需要 QGC）。
2. 等 rviz 窗口出现树林地图，听到黑窗口提示"7 架无人机已就位"——之后自动触发，一列六边形队形自动穿林飞向对面、绕开障碍。
3. 看完回黑窗口**按回车**，仿真连同 rviz 一起清理。
4. 注意：这个演示跑的是规划算法仿真（简化飞机模型），**不连 PX4、不用 QGC**，和 A–C 是两套东西。

## 出问题了怎么办

- 任何一步卡住、报错，先**双击 `停止全部.bat`**，等它提示"已清理"，然后重新双击演示脚本再试一次。
- `停止全部.bat` 任何时候都可以点，演示没跑的时候点也没事。

## 常见问题

- **黑窗口里出现一堆英文不动？** 第一次启动时仿真在编译检查和加载模型，等 1–2 分钟；超过 3 分钟还没出画面，点「停止全部」重来。
- **弹不出仿真窗口？** 可能窗口被其他窗口挡住了，看任务栏有没有叫 "Gazebo" 的窗口。
- **飞机没起飞 / 提示出问题了？** 双击「停止全部.bat」，重新再跑一次；还不动就把黑色窗口里的日志路径发给 AI。
- **组会现场没网能跑吗？** 按设计不需要联网，但还没实际断网测过（Gazebo 启动时会尝试联网查模型库，断网时可能多等一会儿）；彩排时请断网跑一遍确认。
- **黑窗口最后冒出一行 QGC 的英文 Warning（Communication error…）？** 已修（QGC 不再往黑窗口里打日志）。就算碰到也无害——那是仿真关掉后地面站收不到数据的正常提示。
- **演示中途想停？** 直接双击「停止全部.bat」。
