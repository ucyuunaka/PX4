## 场次文件夹内部约定

以 `组会-1/` 为样板：

| 条目 | 内容 |
|---|---|
| `组会-N.pptx` | 成品 PPT |
| `process/` | 内容主稿、页结构计划、证据索引、演讲准备等工作文档；入口是该目录的 README |
| `assets/` | 本次用到的图片/GIF/日志/数据，按 `official/`（官方文档图）、`external/`（开源项目素材）、`sitl/`（本机实测）等来源分类；`assets/README.md` 登记每个文件的原始出处 |
| `research/` | 外部调研的提示词、原始产出（`raw/`）、出处核查表（`sources.md`） |
| `ori_ppt/` | 本次 PPT 的制作来源记录（制作项目落点等） |
| `history/` | 被取代的早期方案，只作留档 |

## 制作规范

- **PPT 制作一律走 ppt-master 流程**：`U:\ucy\Code\reference\ppt-master`（制作项目存放在其 `projects/` 下，场次文件夹的 `ori_ppt/` 记录对应落点）。
- **内容稿先行**：先在 `process/` 写内容主稿（每页上屏文字、图示、引用、讲述提示），再制作 PPT 文件；讲述提示进演讲者备注。
- **引用规则**：不引用 `.cs/` 内部内容；其余来源须注明本地路径或云端 URL。标注只留三类：官方/外部素材标"官方示例/项目名"；本机仿真标"本机 SITL 实测，非实机"；版本事实如实讲。
- 素材先入 `assets/` 并登记出处，再进 PPT；调研 AI 的产出先入 `research/` 核查，不直接上屏。
